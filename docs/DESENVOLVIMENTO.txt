API CAMADA 1 (RESUMO)
---------------------
Base: /api/v1/ | Header obrigatório: X-Tenant-Id (GUID)
Header opcional: X-Actor-Id (audit log)
Erros: RFC 7807 | Paginação: ?page=1&pageSize=20

Recursos CRUD:
  /skills, /people, /people/{id}/skills, /people/{id}/unavailabilities
  /clients, /projects, /allocation-needs, /allocations
  /tenants (POST bootstrap), /users

Auth (dev):
  POST /auth/dev-token  → Bearer JWT (tenant_id + sub)
  Fallback: X-Tenant-Id + X-Actor-Id

Leitura / regras:
  GET /projects/{id}/people
  GET /people/{id}/projects
  GET /allocations/conflicts?personId=&projectId=&from=&to=
  GET /audit-logs?entityType=&entityId=&action=&from=&to=
  GET /capacity/overview?from=&to=
  GET /capacity/bench?from=&to=
  GET /capacity/projects-understaffed | GET /projects/understaffed
  POST /simulations/project-feasibility
  GET /capacity/people/{id}/availability?from=&to=
  GET /capacity/projects/{id}/staffing-gaps
  GET /capacity/people-available?from=&to=&minAvailablePercent=

Health (sem tenant): GET /api/v1/health
Swagger (Development): http://localhost:5203/swagger
