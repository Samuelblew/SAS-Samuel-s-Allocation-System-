STACK
-----
  React 19 + Vite 6 + TypeScript 5.8
  TanStack Query v5 — cache e mutations
  React Hook Form + Zod — formulários e validação client-side
  Tailwind CSS v4 — tokens `ias-*` em index.css
  Vitest + Testing Library — testes unitários e de componente

LOCAL
-----
  cd Frontend
  npm install
  npm run dev          → http://localhost:5173 (proxy /api → :5203)
  npm run test         → testes (Vitest)
  npm run lint         → ESLint
  npm run build        → tsc + vite build

CI
--
  .github/workflows/frontend-ci.yml
  Em cada PR/push em Frontend/: lint + test + build (Node 22)

ESTRUTURA
---------
  Frontend/src/
    pages/           — telas por rota (uma página = um domínio)
    components/      — UI reutilizável (DataTable, StatCard, FormField…)
    components/forms/— FormField (label + erro Zod/RHF)
    context/         — Theme, Locale (i18n), Settings (tenant/actor)
    lib/
      api.ts         — cliente HTTP + ApiError (RFC 7807)
      errors.ts      — getErrorMessage()
      schemas/       — Zod schemas + to*Payload() por entidade
      ui.ts          — classes CSS do design system
      types.ts       — tipos espelhando DTOs da API
    i18n/
      messages.ts    — chaves PT/EN (t('key') ou t('key', { var }))
      domain.ts      — labels de enums (status, prioridade…)

DESIGN SYSTEM
-------------
  Usar SEMPRE tokens e componentes compartilhados:

  | Necessidade        | Usar                          |
  |--------------------|-------------------------------|
  | Botão primário     | btnPrimaryClass               |
  | Botão secundário   | btnGhostClass                 |
  | Botão sucesso      | btnSuccessClass               |
  | Input / select     | inputClass + FormField        |
  | Formulário inline  | formRowClass                  |
  | Lista              | DataTable + TableActions      |
  | KPI                | StatCard                      |
  | Carregando         | LoadingState                  |
  | Lista vazia        | EmptyState                    |
  | Título de seção    | SectionTitle                  |
  | Chip / tag         | chipClass                     |

  NÃO usar inline: bg-slate-*, text-indigo-*, bg-emerald-*

FORMULÁRIOS (PADRÃO OBRIGATÓRIO)
--------------------------------
  1. Schema Zod em lib/schemas/<entidade>.ts
  2. useForm({ resolver: zodResolver(schema) })
  3. FormField para label + mensagem de erro
  4. to*Payload() para normalizar antes do POST/PUT
  5. getErrorMessage() no onError das mutations

  Exemplo (SkillsPage — referência):

    const form = useForm<SkillFormValues>({
      resolver: zodResolver(skillFormSchema),
      defaultValues: { name: '', category: '' },
    })

    const onSubmit = form.handleSubmit((values) => {
      create.mutate(toSkillPayload(values))
    })

I18N
----
  Todas as strings visíveis ao usuário devem usar t('chave').
  Interpolação: t('form.people.skillsOf', { name: person.name })
  Labels de enum: useDomainLabels() (personStatus, projectStatus…)
